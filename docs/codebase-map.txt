## File Descriptions

### Core Configuration Files
- **package.json**: Project dependencies and scripts
- **next.config.js**: Next.js configuration settings
- **tailwind.config.js**: Tailwind CSS configuration
- **tsconfig.json**: TypeScript configuration
- **eslint.config.mjs**: ESLint configuration

### Main Application Files
- **src/app/page.tsx**: Main homepage component
- **src/app/layout.tsx**: Main layout component with header/footer
- **src/lib/blogData.ts**: Centralized blog posts data structure

### Blog System Files
- **src/app/blog/page.tsx**: Blog listing page
- **src/app/blog/BlogContent.tsx**: Blog listing component
- **src/app/blog/[id]/page.tsx**: Individual blog post page
- **src/app/blog/posts/**: Individual blog post files (currently 5 exist)

### Layout Components
- **src/components/layout/Header.tsx**: Navigation header with dropdown menus
- **src/components/layout/Footer.tsx**: Site footer with contact info

### Service Pages
- **src/app/leistungen/**: Multiple service pages for different valuation services
- **src/app/immobiliengutachter-***: City-specific landing pages

### Contact and Information Pages
- **src/app/kontakt/**: Contact page with information
- **src/app/ueber-uns/**: About us page
- **src/app/faq/**: Frequently asked questions
- **src/app/team/**: Team member profiles

### Special Pages
- **src/app/immobilienwert/**: Immobilienwert calculator
- **src/app/marktberichte-immobilien-osnabrueck/**: Market reports
- **src/app/immobilien-abschreibung/**: Asset depreciation information
